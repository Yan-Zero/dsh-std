# Changelog

Changes to `@dsh-std/workspace` are recorded here.

## 0.1.1-rc.1

- Aligned the package with the workspace `0.1.1` prerelease line without changing the existing Workspace protocol semantics.

## 0.1.0-rc1

- Defined workspace catalogs, target selection, progress, mutations, and session membership.
- Added typed clients and implementations for local and connection-backed workspace domains.
