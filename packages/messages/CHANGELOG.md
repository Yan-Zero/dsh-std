# Changelog

Changes to `@dsh-std/messages` are recorded here.

## 0.1.1-rc.1

- Added optional structured scope, correlation, redaction, payload schema, and envelope version metadata.
- Preserved the complete rc1 event shape and its validation semantics.

## 0.1.0-rc1

- Defined message observation events with privacy classification and structured content blocks.
- Added schemas and validators for the portable text and image subset.
